# 🔍 Text Search

A web app that lets users search through text and instantly highlights matching results.


---

## ✨ Features

- Search text in real time as you type
- Highlight every match in the results
- Show the number of matches


---

## 🛠️ Tech Stack

- React (Vite)
- JavaScript
- CSS / Bootstrap]

---

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mcmelhem/text-search.git
cd text-search/text-search
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the app

```bash
npm run dev
```

Then open the local URL shown in the terminal (usually http://localhost:5173).

---

## ⚙️ How It Works

1. The user types a search term in the input field.
2. The app filters  the text for matches as the input changes.
3. Matching parts are wrapped and highlighted in the results.
